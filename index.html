Project 01
01 워디/워드북 시스템 기획 엔씨소프트 · 호두잉글리시 · 게임 기획자

영어 학습 게임 호두잉글리시에서 단어 학습의 핵심 시스템인 워디/워드북을 기획했습니다. "세상이 곧 사전, 사물과의 대화"라는 컨셉 아래 3D 게임 세계의 사물(워디)을 영어 단어와 연결하는 게임 메커닉을 설계했습니다.

초기 설계 → FGT(사용자 테스트) → 문제점 도출 → 개선안(Caring Wordie) 기획까지 전체 사이클을 담당했습니다.

  • 인터랙션 플로우: 알림 수신 → 워디 클릭 → 음성 입력 → 수집 성공/실패 → 보상
  • 단계별 연출: 수집 전/중/후 워디 상태, 애니메이션, 이펙트 정의
  • 예외 처리: 음성 입력 실패, 재시도 유도, 쿨타임 로직
  • General/Special Wordie 유형별 프레임워크로 다수 콘텐츠 양산

02 생성형 AI 활용 영어 학습 기획 아키핀 · 헬로루디 · 총괄 PM

학습자의 발화에 따라 생성형 AI가 실시간으로 이미지를 그려주는 인터랙티브 영어 학습 콘텐츠를 기획했습니다.

  • Let's Draw Together — 제플린이 제시한 문장을 따라 읽어 그림을 그리는 가이드 모드
  • Draw It My Way — 제플린과 자유롭게 대화하며 그림을 그리는 창작 모드

발화 → AI 이미지 생성 → 결과 확인 → 재시도의 전체 인터랙션 플로우를 설계하고 예외 케이스와 복귀 경로까지 기획서에 담았습니다.

구독 및 회원가입 온보딩 플로우(4차 업데이트)도 담당했습니다. 게스트/무료체험/구독/회원가입 유저 4가지 유형별 분기를 설계하고 App Store · Google Play 등록 및 심사 대응까지 수행했습니다.

03 LMS 플랫폼 기획 — Kidsloop 웹-앱 연동 키즈룹 · 프로덕트 매니저

국제 사립학교 대상 LMS 플랫폼의 PM으로 웹-앱 연동 사용자 플로우 전체를 설계했습니다. Figma로 프로토타입을 제작하고 개발 수명 주기 전반을 관리했습니다.

  • Integrated Assessment — 학급 전체 홈펀스터디 평가를 한 페이지에서 처리
  • Drawing Feedback — 교사가 학생 제출 이미지 위에 드로잉 피드백
  • Learning Outcome Setting — LO별 자동 평가 임계값 설정 기능
  • Adaptive Review — 교사 설정 → 학생 앱 실행 → 대시보드 결과 확인 플로우

Badanamu ESL 학습 미니게임 기획, 앱 다운로드부터 결제까지 온보딩 플로우 설계, 학부모 대시보드 디자인도 담당했습니다.
